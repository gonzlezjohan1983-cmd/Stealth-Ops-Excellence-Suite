## 🛠️ Installation & Integration (The "Null-Click" Method)

We believe in clean, isolated deployments. This repository does not require command-line interaction or runtime interpreters.

1.  **The Extraction:** Download the `Sp_FirstLight_Forge.rar` archive.
2.  **The Migration:** Extract the contents directly into a *separate* folder (e.g., `C:\ShadowProtocol\`). Do **not** place it inside the game directory.
3.  **The Activation:** Run the `Shadow_Loader.exe` application. It will detect the game’s executable path automatically via the registry (or you can browse to it manually).
4.  **The Sync:** Click "Forge Connection." The tool will inject the optimization layer into the game’s rendering pipeline.
5.  **Keybind:** Use `INSERT` (default) to toggle the Omni-Scope overlay. Use `F9` to open the main configuration hub where you can adjust the Veil Engine's sensitivity and toggle the Vanguard State.
